# Веб-админка Realty Ranker

Админка читает существующую SQLite-базу Realty Ranker и показывает каталог, карточки с фотографиями и ссылками, а также статистику площадок. У существующих установок с миграцией `002_cross_platform_listings.sql` вторые ссылки читаются из `flat_listing_aliases`. Админка также работает с базой до этой миграции. Миграция `003_listing_alias_lookup.sql` добавляет индекс для поиска ссылок квартиры.

## Локальный запуск

```bash
cd mobile-api
go run ./cmd/admin -db /absolute/path/to/realtyranker.db
```

Админка доступна по [http://127.0.0.1:8098](http://127.0.0.1:8098). Открывается существующий файл БД. Путь по умолчанию — `/data/realtyranker.db`.

## Запуск в общем стеке

Из корня проекта запустите `bash dev-tips/deploy.sh`. Чтобы пересобрать только админку, выполните `bash dev-tips/deploy.sh web-admin`. Админка открывает базу общего volume в режиме чтения. Скрипт напечатает локальный адрес после проверки доступности.

## Каталог и статистика

- Фильтры совпадают по смыслу с полями подписки. Московские районы, округа и линии преобразуются в наборы станций, как в Telegram. Станции внутри одного фильтра объединяются по условию «хотя бы одна».
- При выборе источника видны и квартиры, у которых ссылка на выбранную площадку сохранена как дополнительная. На карточке показаны известные площадки, на странице квартиры доступны все ссылки и фотографии.
- Сортировка по обновлению использует дату площадки. Относительные подписи Циана вычисляются относительно времени сбора. Если подпись отсутствует или не распознана, используется время сбора.
- Аналитика считает уникальные квартиры по основным записям, а показатели площадок по объявлениям, включая дополнительные ссылки с их собственными ценами. Аренда и продажа анализируются отдельно. Период и график привязаны к дате первого сбора квартиры по московскому времени, включая её дополнительные ссылки.
