# Realty Ranker Mobile API

Репозиторий содержит HTTP API для приложения Realty Ranker на iOS и веб-админку. Оба сервиса используют общую SQLite-базу проекта.

| Команда | Назначение |
| --- | --- |
| `cmd/mobileapi` | Вход по идентификатору устройства, сессии, подписки, выдача и карточки квартир |
| `cmd/admin` | Каталог с фильтрами, карточки со ссылками на площадки и статистика в режиме чтения |

## Запуск в Docker

Поместите `mobile-api` и `dev-tips` рядом в каталоге RealtyRanker. Из этого каталога запустите:

```bash
bash dev-tips/deploy.sh mobile-api web-admin
```

Скрипт соберёт образы, применит миграции SQLite и выведет адреса сервисов. Для запуска всего стека выполните `bash dev-tips/deploy.sh`. По умолчанию API использует порт `8090`, а админка доступна по [http://127.0.0.1:8098](http://127.0.0.1:8098). Конечная точка проверки API — `GET /healthz`.

При первом запуске скрипт создаёт локальный файл `jwt_secret` для подписи токенов. Храните его вне Git. Чтобы действующие токены оставались валидными при переносе базы, сохраните тот же ключ. [Настройки API](config.yaml)

## Разработка

Для запуска вне Docker нужен Go 1.25 или новее. Команды из каталога `mobile-api`:

```bash
go test ./...
go run ./cmd/admin -db /absolute/path/to/realtyranker.db
```

Для полного прогона интеграционных тестов нужен соседний репозиторий `dev-tips`. Если он находится в другом каталоге, укажите путь к `migrations/sqlite/001_initial.sql` через `REALTYRANKER_TEST_SCHEMA`.

Параметры админки и правила расчёта статистики описаны отдельно. [Документация админки](ADMIN.md)
